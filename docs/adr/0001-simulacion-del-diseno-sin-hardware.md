# Simular el diseño y declarar el grado de evidencia

El grupo confirmó que no existe robot físico ni hardware. Se construyó una simulación del diseño SCARA con geometría reutilizada, cinemática, dinámica parametrizada, comunicación externa y fallas reproducibles, para apoyar una construcción futura o trabajos docentes posteriores.

La entrega se valida contra el CAD, cálculos y escenarios especificados. Cada propiedad física conserva su procedencia y distingue valores confirmados, calculados y estimados. La alternativa de exigir sincronización y calibración experimental impediría completar el proyecto actual; si se construye el robot, sus mediciones podrán reemplazar parámetros y ampliar la validación sin presentar las estimaciones como mediciones reales.

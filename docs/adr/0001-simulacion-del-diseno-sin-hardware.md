# Simular el diseño y declarar el grado de evidencia

El grupo confirmó que no existe robot físico ni hardware. Se construirá una simulación del diseño SCARA con geometría reutilizada, cinemática, dinámica parametrizada, comunicación externa y fallas reproducibles, para apoyar una construcción futura o trabajos docentes posteriores.

La entrega se validará contra el CAD, cálculos y escenarios especificados. Cada propiedad física conservará su procedencia y distinguirá valores confirmados, calculados y estimados. La alternativa de exigir sincronización y calibración experimental impediría completar el proyecto actual; si más adelante se construye el robot, sus mediciones podrán reemplazar parámetros y ampliar la validación sin presentar estimaciones anteriores como mediciones reales.
